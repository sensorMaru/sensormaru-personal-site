# SensorMaru Personal Site

Static personal website for 沈智宇.

## Local development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run validate:content
npm run build
```

## Deployment

1. Buy `sensormaru.com`.
2. Point the domain to Cloudflare nameservers.
3. Connect the Git repository to Cloudflare Pages.
4. Assign `sensormaru.com` as the custom domain.
5. Later, move `design-award-meta-search` into the same domain family if the hosting is migrated.
